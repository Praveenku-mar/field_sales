# Screencast script (about 3 minutes, English)

For the App Store review submission. Record on the development store with the demo data, in
Chrome, at 1600x900. Narration in quotes; on-screen actions in brackets.

**0:00 – Install (25 s)**
[Shopify admin → Apps → open the Field Sales listing → Install.]
"Field Sales is for brands whose reps sell to retail shops. I install it from the App Store."
[Shopify's permission screen.] "It asks for products, inventory, locations, customers, draft
orders and orders — to show stock, create retailers as customers and send orders." [Install.]

**0:25 – Embedded dashboard (20 s)**
[App opens inside the admin.] "Field Sales opens inside the admin. The dashboard shows today's
visits, this month's orders and the team." [Point at the Field Sales menu in the admin sidebar.]

**0:45 – Settings (15 s)**
[Settings.] "The store is connected. Here are the granted scopes, the locations reps sell from,
and the order mode — drafts or confirmed orders."

**1:00 – Invite a rep (20 s)**
[Sales Reps → New Sales Rep → email, name, reports to, Send welcome email → Create.]
"Managers add reps here. The rep gets an email to set a password and uses the Field Sales app on
their phone."

**1:20 – Rep check-in with GPS (25 s)**
[Phone (or device emulation): sign in as the demo rep → Visits → today's visit → Check In → allow
location.] "On the phone, the rep checks in at the shop. The GPS position is checked against the
shop's location."

**1:45 – Order with live stock (25 s)**
[New Order → add two products → quantities → Submit.] "The rep takes an order. Stock is read live
from the store's location, and the order is checked again on submit."

**2:10 – Order in the store (15 s)**
[Back in the admin → Orders (or Draft orders) → the new order.] "The order is now in the store,
with the retailer as the customer and the rep and order number in its fields."

**2:25 – Sync failure and retry (15 s)**
[Field Sales → Sync Failures → the prepared failed order → read the message → fix the stock →
Retry.] "If the store refuses an order, the reason is shown here. After fixing it, Retry sends it
again."

**2:40 – Commission (10 s)**
[Commission page.] "Commission is calculated for each rep when store orders are paid or fulfilled."

**2:50 – Uninstall (10 s)**
[Settings → Apps → Field Sales → Uninstall.] "Uninstalling removes access to the store right
away. Shopify's data deletion request then removes the shop's personal data."

End: about 3:00.
